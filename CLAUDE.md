# Kit de reels y contenido

Este repo es un kit para producir reels 9:16 y piezas de Instagram con un estilo ya aprobado.

- **Leé `SKILL.md` completo antes de hacer cualquier cosa.** Ahí está el flujo, el estándar de calidad y los errores a evitar.
- El usuario va a decir qué quiere y para quién. Producí todo de punta a punta (guion, voz, video, verificación, caption) sin frenar a preguntar, salvo que falte algo imposible de decidir.
- Respondé en español rioplatense. Sin emojis en el contenido.
- Voz por defecto: `es-MX-JorgeNeural` a +8 % (`motor/voz.py`).
- Nunca pidas ni pegues claves de API en el chat ni en el código.
